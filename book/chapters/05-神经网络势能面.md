# 第 5 章　神经网络势能面

## 1. 本章导读

势能面（potential energy surface, PES）把几何坐标映射为能量。AutoQuantum 不把量子化学程序藏在神经网络之后：`AbInitioData` 负责承载或采样数据，`FeedForwardNN` 用纯 NumPy 拟合，`PESNN` 则把模型包装成动力学模块可调用的势函数与力函数。你将看到，一个看似简单的多层感知机（MLP）为何必须有线性输出层，以及本章的核心——如何通过“对梯度再做一次反向传播”训练力。

本章使用 Hartree、Bohr 和电子质量单位，并令 $\hbar=1$。第 3 章讨论 PES 的来源，本章讨论如何把离散数据变成光滑代理面；第 5、6 章会分别在这个面上做定态与含时计算。数学记号可回查“01 数学预备”，算符与边界可回查“02 量子力学基础”；二维应用、数值门控、发布接口与更高级方法分别见“08 二维反应动力学”“09 数值验证”“10 软件架构与发布”“11 进阶专题”，单位和符号汇总在“附录”。

## 3. 新手路径

把 MLP 想成一条“配料加工线”：坐标 $x$ 经过几层称量与非线性混合，最后得到能量 $V$。网络宽，不代表它天然理解分子；它只从样本中找规律。

先看最小问题。输入两个坐标 $(R,r)$，输出势能。即使只有两层权重，非线性激活也能把直线分段弯折；层层叠加后，可以逼近很光滑的曲面。这就是万能逼近定理的直觉：足够宽的浅层网络具有通用表达力，但“能表达”不等于“容易训练”，也不保证外推可靠。

为什么输出层不能也用 `tanh`？因为 $\tanh z\in(-1,1)$。若势能为 2 Hartree，网络无论怎样调整，最多输出接近 1；若所有目标先减均值、除标准差，预测似乎正常，但旧模型重新加载或更换尺度后就会出错。v0.3.1 因而让隐藏层保留 `tanh`，最后一层直接输出 $z$。

训练时，每个样本都给“坐标—能量—梯度”三元组，就不只是背答案，还要求曲线斜率正确。后者比能量误差更严格，也是本章最有价值的部分。

## 4. 公式与推导

设网络有 $L$ 个权重层，隐藏层激活为 $f$。记第 $l$ 层输入、仿射量、输出为 $a_l,z_l=a_{l-1}W_l+b_l,a_l$。隐藏层取 $a_l=f(z_l)$，输出层取 $a_L=z_L$。于是

$$
z_l=a_{l-1}W_l+b_l,\qquad
a_l=\begin{cases}f(z_l),&l<L,\\z_l,&l=L.\end{cases}
\tag{4.1}
$$

标量能量损失 $L_V=\frac1n\sum_i(\hat y_i-y_i)^2$ 的输出伴随为 $\delta_L=a_L-y$。对普通前向中的 $z_l=a_{l-1}W_l+b_l$，反向规则是

$$
\bar W_l=a_{l-1}^{T}\delta_l,\qquad
\bar b_l=\sum_i\delta_{l,i},\qquad
\delta_{l-1}=(\delta_lW_l^T)\odot f'(z_{l-1}).
\tag{4.2}
$$

`model.py::_backward` 返回的是 $\frac12L_V$ 的精确梯度；这在代码中虽不常写成 $2\delta$，但已经在 force loss 的伴随因子里配平。默认全批量优化相当于在全部 $n$ 个点上同时求方向。

Xavier/Glorot 初始化采用

$$
W_{ij}\sim U\left(-\sqrt{\frac{6}{n_{in}+n_{out}}},
\sqrt{\frac{6}{n_{in}+n_{out}}}\right),
\tag{4.3}
$$

使前向激活和反向梯度的方差在层间大体稳定。偏差初始化为 0。万能逼近定理说明，只有一个隐藏层的网络在激活函数满足相应连续、非多项式等条件时，稠密子集上的连续函数可被任意逼近；当前若干隐藏层的 `tanh` 网络是这一思想的实用化，而不是定理本身保证训练成功。

对任意 $d$ 维输入，训练器构造网络层数 $[d,h_1,\ldots,h_q,1]$。训练划分上的标准化为

$$
x'=\frac{x-\mu_x}{s_x},\qquad
y'=\frac{y-\mu_y}{s_y}.
\tag{4.4}
$$

推理仍接受物理单位：内部用 $x'$，输出乘 $s_y$ 再加 $\mu_y$。因此解析输入梯度必须补上链式因子：

$$
\frac{dV}{dx_j}=s_y\frac{\partial\hat y'}{\partial x'_j}\frac1{s_{x_j}}.
\tag{4.5}
$$

$\mu_x,s_x,\mu_y,s_y$ 由 `set_normalization` 写入模型，并由 `save/load` 一起持久化；只保存权重却遗漏这些量，部署时就改变了函数。

Adam 对每个参数块维护一阶矩 $m_t$、二阶矩 $v_t$：

$$
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t,\quad
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2,
$$
$$
\theta_{t+1}=\theta_t-\eta\frac{\hat m_t}{\sqrt{\hat v_t}+\varepsilon},
\quad(\beta_1,\beta_2,\varepsilon)=(0.9,0.999,10^{-8}).
\tag{4.6}
$$

`TrainingConfig.batch_size=0` 是全批量；若 `adam_beta1=0`，代码退回朴素 `train_step`。默认早停不是“微小变化就算进步”，而是只有

$$
L_{val}<0.999L_{best}
\tag{4.7}
$$

才刷新最佳状态；连续 100 轮无此相对改进才停止，结束前恢复最佳权重。这保护了全批量 Adam 慢收敛的长尾。

力训练采用联合物理单位损失

$$
L=L_V+wF\operatorname{mean}(\nabla_x\hat y-\nabla_xy)^2.
\tag{4.8}
$$

令 $g=\partial\hat y/\partial x$，其伴随为 $\bar g=2w(g-t)/(nd)$。`input_gradient_backward` 对标量 $\Phi=\sum\bar g g$ 再做一次反向传播，即 reverse-over-reverse。关键是输入梯度图中的 $T=GW^T$ 与普通前向反向的转置方向不同：普通 backprop 用 $G=W\delta^T$，而此处由 $T=GW^T$ 得到 $dW=\bar T^TG$、$\bar G=\bar TW$。此外 $g$ 经 $f'(z)$ 依赖前向图；要得到偏置梯度，就必须继续传播 $f''(z)$ 项。于是 $f''(z)$ 正是 force gradient 能进入 bias gradient 的桥梁。

## 5. 与代码的对应

输入网格必须是 $(n,d)$；一维向量会 reshape。标准化、预测、反标准化在 `FeedForwardNN` 中闭环：

```python
def predict(self, X):
    X = self._shape_input(X)
    Xn = self._normalize_x(X)
    activations, _ = self.forward(Xn)
    return self._denormalize_y(activations[-1]).ravel()
```

`PESNN.evaluate` 直接转调 `predict`，而 `PESNN.gradient` 转调 `model.gradient`，所以第 5、6 章可以把 NN 当作普通 PES 使用。`autoquantum/pes/abinitio.py::AbInitioData.sample_function` 从任意接受 $(n,d)$ 的函数生成能量和中心差分梯度；它不是 ASE/PySCF 后端。

`NNTrainer.train` 的全批量 Adam 路径是“前向算能量伴随；若是力训练，再算输入梯度伴随；最后分别更新参数”。`max_train_points` 用等距索引子采样；标准差统计只来自训练划分，避免验证信息泄漏。

double backprop 的关键实现只有十余行，以下截取核心状态定义：

```python
T[l] = G[l] @ self.weights[l].T
if l > 0:
    G[l - 1] = T[l] * self.activation_deriv(zs[l - 1])
```

第二遍先给 $\bar T_0$，再把激活二阶导产生的 $\bar z$ 送回前向图。发布验证对 tanh、sigmoid、relu 的全部权重和偏置做中心差分检查，最大相对误差约 $10^{-10}$。

固定种子 Eckart 二维实测给出可复现量级：纯能量拟合为 $V$ RMSE $4.6\times10^{-3}$、梯度 RMSE $2.2\times10^{-2}$；CLI 力训练实测为 $4.5\times10^{-4}$ 和 $2.1\times10^{-3}$（release 表格的另一组 $w=2.0$ 训练为梯度 $2.3\times10^{-3}$）。这说明梯度监督能正则化势能面，但不等于所有体系都必然得到同样增益。

## 6. 动手实验

下面的短程序只使用真实 API。它在一个解析二维面上同时检查能量预测、解析梯度与有限差分一致性：

```python
import numpy as np
from autoquantum.nn.train import NNTrainer, TrainingConfig

def f(X):
    return np.sin(X[:, 0]) * np.exp(-0.5 * X[:, 1]**2)

X = np.random.default_rng(1).uniform(-2, 2, (1000, 2))
dY = np.column_stack((np.cos(X[:, 0])*np.exp(-0.5*X[:, 1]**2),
                      -X[:, 1]*f(X)))
cfg = TrainingConfig(hidden_layers=[32, 32], epochs=300,
                     lr=0.01, force_weight=1.0)
model, history = NNTrainer(cfg).train(X, f(X), dY=dY)
g = model.gradient(X[:10])
h = 1e-6
fd = (model.predict(X[:10]+h*np.array([1, 0]))
      - model.predict(X[:10]-h*np.array([1, 0]))) / (2*h)
print(np.max(np.abs(g[:, 0]-fd)))
```

## 7. 常见陷阱

- 不要把验证集统计量用于标准化；`NNTrainer` 已避免，但手工预处理容易犯错。
- 不要只看 V RMSE。反应概率对势垒形状和斜率敏感，梯度 RMSE 往往更早暴露问题。
- 不要手写 `X = X/std(X)` 后只保存权重；`x_mean/x_scale/y_mean/y_scale` 必须随模型保存。
- 不要期待 `tanh` 输出层能表示 2 au 的势能；v0.3.1 的修复不是可选项。
- 当前网络没有对称化、原子置换不变量或显式物理特征，域外行为没有保证。
- 全批量并非免费；大网格上应做训练点数、步数、宽度的收敛检查。模型文件使用 pickle，只加载可信来源。

## 8. 高手专栏

万能逼近定理讨论“存在性”，却不告诉我们样本复杂度、损失景观或外推误差。MLP 的归纳偏置弱，而 PES 具有键交换、转动和平移等结构；仓库当前尚未注入这些先验，因此工程上更依赖覆盖良好的采样域。

Adam 的分母归一化沿用 AdaGrad/RMSProp 思路，但二阶矩指数衰减会“遗忘”很旧的梯度。`eps=1e-8` 防止零分母，却在梯度极小时改变尺度；这与早停阈值一样，是需要按数据量纲检查的经验参数。

double backprop 本质是微分程序对计算图再求一次导。设前向映射为 $F_\theta$，目标依赖 $G_\theta=\partial F_\theta/\partial x$，那么力损失关于参数的导数包含 $\partial^2F_\theta/\partial x\partial\theta$。仅对输出伴随做普通 backprop 会漏掉这一混合二阶项。`sample_function` 的有限差分梯度有截断误差与舍入误差；若未来接入高精度从头算解析梯度，力训练链会更可靠。

## 9. 本章小结 + 自测题

本章从普通 MLP 走到可提供解析力的 PES。线性输出解除值域陷阱，标准化状态持久化保持部署一致，输入梯度把能量与力连接起来，double backprop 则保证力损失能更新所有参数。AutoQuantum 的成绩是实测改进，不是普适精度保证；没有物理特征和对称性时，域外风险仍然存在。
