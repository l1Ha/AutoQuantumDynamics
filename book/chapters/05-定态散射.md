# 第 5 章　定态散射

## 1. 本章导读

定态散射把时间冻结，只问一个问题：一个粒子以给定能量接近势垒，最终穿过去的概率是多少？在量子力学中，概率不仅取决于粒子的动能，还取决于波函数的相位如何穿过势垒。AutoQuantum 用一维 Numerov 递推实现这一定态方法，并把透射率 $T(E)$ 和反射率 $R(E)$ 扫成曲线。

本章先理解一维散射，再审视仓库中的二维实验求解器。务必区分：前者是有明确递推和通量含义的数值路径；后者只适合展示趋势，不能作为定量反应动力学结论。第 4 章的 NN-PES 可直接作为这里的势函数，第 6 章将改用含时波包，并解释为什么包络平均不能与中心能量点值硬比。基础公式见“01 数学预备”“02 量子力学基础”，测试门槛与发布边界见“08 数值验证”“09 软件架构与发布”，更完整的路线见“03 势能面”“07 二维反应动力学”“10 进阶专题”和“附录”。

## 2. 学习目标

1. 从定态薛定谔方程得到一维局部波数；
2. 理解左右渐近区的平面波振幅和概率流；
3. 推导 Numerov 递推及其四阶精度；
4. 解释禁阻区、垒上和垒下行为；
5. 分辨已验证的 1D 方法与实验性的 2D 路径。

## 3. 新手路径

把波函数想成一条起伏的绳，势垒则是地形。粒子不是小球，绳在地形中传播时会反射、叠加和干涉。增大能量不是简单“翻过山”，而是改变波长与相位关系，因此 $T(E)$ 可以快速上升，也可能出现振荡。

假设左右远方都是同一零势能。一个右行波可写成 $\psi=Ae^{ikx}$，反射波为 $Be^{-ikx}$。$A$ 是从右侧入射的振幅，$B/A$ 给出反射振幅；如果左右势能不同，透射概率还必须乘波数比。

初学者最容易先问：波函数是概率吗？不是。波函数是概率幅；$|\psi|^2$ 才给出位置概率密度，而散射输出要由电流决定。第二步才是用数值递推从右向左重建整条波函数，并在左侧渐近区拟合 $A,B$。

## 4. 公式与推导

令 $\hbar=1$。一维定态薛定谔方程为

$$
-\frac{1}{2m}\frac{d^2\psi(x)}{dx^2}+V(x)\psi(x)=E\psi(x).
\tag{5.1}
$$

定义局部量

$$
k^2(x)=2m[E-V(x)].
\tag{5.2}
$$

于是 $E>V$ 时 $k^2>0$，波函数振荡；$E<V$ 时 $k^2<0$，令 $\kappa=\sqrt{-k^2}$，其包络按 $e^{\pm\kappa x}$ 衰减。经典上低于垒顶能禁止穿越的粒子仍可隧穿，这正是纯量子行为。

在左右渐近区，设 $V_L,V_R$ 为代码所用边界平均势，则

$$
k_L=\sqrt{2m(E-V_L)},\qquad
k_R=\sqrt{2m(E-V_R)}.
\tag{5.3}
$$

全局解的渐近形式为

$$
\psi(x)\sim A e^{ik_Lx}+B e^{-ik_Lx}\quad(x\rightarrow-\infty),
$$
$$
\psi(x)\sim C e^{ik_Rx}+D e^{-ik_Rx}\quad(x\rightarrow+\infty).
\tag{5.4}
$$

定态散射要求右端只保留向外行波 $C$。从概率密度 $j=\operatorname{Im}(\psi^*\psi'/\mu)$ 出发，单位宽度下

$$
j_R=|C|^2k_R/\mu,\qquad j_L=|A|^2k_L/\mu-|B|^2k_L/\mu.
\tag{5.5}
$$

归一化 $C=1$ 后，透射与反射为

$$
T=\frac{k_R}{k_L}\left|\frac{C}{A}\right|^2,\qquad
R=\left|\frac BA\right|^2.
\tag{5.6}
$$

实势、无吸收且边界足够远时，$T+R=1$。`QuantumScattering1D` 最后还除以实测总量并裁剪到 $[0,1]$；这是有限网格后的数值清洗，不应掩盖严重发散。

将式 (5.2) 代入方程得到 $\psi''+k^2\psi=0$。等距网格步长为 $h$。把 $\psi_{j\pm1}$ 在 $j$ 点展开并消去奇次项，得到

$$
(1+\tfrac{h^2k^2_{j+1}}{12})\psi_{j+1}
-2(1-\tfrac{5h^2k^2_j}{12})\psi_j
+(1+\tfrac{h^2k^2_{j-1}}{12})\psi_{j-1}=0.
\tag{5.7}
$$

解出下一格即 Numerov 递推。权重恰是

$$
1+\frac{h^2k^2}{12},\qquad
2-\frac{5h^2k^2}{6},\qquad
1+\frac{h^2k^2}{12},
\tag{5.8}
$$

因为“下一格—本格”组合中 $2[1-5h^2k^2/12]=2-5h^2k^2/6$。与二阶中心差分的 $1,2,1$ 相比，$k^2$ 项至少具有四阶符号结构；对光滑解，传播解的全局误差通常为 $O(h^4)$。若势能在网格点间不光滑或 $h$ 太粗，该结论会退化。

为避免右端混入向左增长的指数分支，代码设置 $\psi_N=1$、$\psi_{N-1}=e^{-ik_Rh}$，然后按式 (5.7) 从右向左递推。左侧匹配采用 $\psi_j=Ae^{ik_Lx_j}+Be^{-ik_Lx_j}$；因子 $e^{ik_Lx_j}$ 在振幅比中消去，得到代码中的

$$
A=\frac{\psi_{j+1}-\psi_j e^{-ik_Lh}}{e^{ik_Lh}-e^{-ik_Lh}},
\qquad B=\psi_j-A.
\tag{5.9}
$$

在势垒峰以下，若垒又高又宽，禁阻区长，$T$ 通常指数小；接近垒顶时隧穿与干涉增强，$T$ 可迅速上升；高于垒顶时经典通道开放但仍有干涉。更高能下变化趋于平缓，却不保证单调。

## 5. 与代码的对应

`autoquantum/dynamics/quantum_1d.py::QuantumScattering1D.solve` 在一次扫描中复用势能网格；`_solve_energy` 逐能量工作。核心递推逐字对应式 (5.7)：

```python
denom = 1.0 + h2 * k2_pad[j - 1] / 12.0
psi[j - 1] = ((2.0 - 5.0 * h2 * k2_pad[j] / 6.0) * psi[j]
              - (1.0 + h2 * k2_pad[j + 1] / 12.0)
              * psi[j + 1]) / denom
```

这里 `k2_pad` 用 edge padding，方便索引。`psi_left`、`psi_left_next` 位于左侧近渐近区；`exp_ikdx`、`exp_mikdx`、`sin_kdx` 提供式 (5.9) 的闭式解。当分母过小时代码 `continue`，但这可能是数值失效信号，不应当作正常物理分支。

该类的输出 `DynamicsResult` 含 `energy`、`transmission`、`reflection` 和 `grid`。注意本实现的 `solve` 接收的是散射总能量 $E$，两端势能由边界区平均得到；若要研究不同渐近通道，应先明确能量零点与势能引用。

`autoquantum/dynamics/quantum_2d.py::QuantumReaction2D` 是另一条路。它只沿 $R$ 做中心差分

$$
\psi_{i+1,j}=(2-h^2k^2_{i,j})\psi_{i,j}-\psi_{i-1,j},
\tag{5.10}
$$

没有 $r$ 方向横向动能算符、没有通道耦合，概率只是入射/出射截面平均振幅比，也未做概率流归一化。模块开头和 engine 都明确警告：只能看势垒形状的定性趋势，不得作定量结论。定量二维反应动力学应转到第 6 章的 `WavePacket2DPropagator`。

对物理质量 $\mu_R=2m_H/3=1224.1$ 的 Eckart 模型，$T(E)$ 很宽：约从 $E=0.004$ au 的接近 0 上升到 $E=0.03$ au 的接近 1。测试注释给出的鲜明例子是：中心能量 $E=0.02$ au 的点值约 0.98，但同一高斯波包的能量加权值约 0.75。差别不是某一方“算错”，而是观测量不同：定态扫描给 $T(E)$，波包给动量分布对 $T$ 的卷积。

## 6. 动手实验

先运行真实一维求解器，观察宽阈值：

```python
import numpy as np
from autoquantum.dynamics import QuantumScattering1D

def sech2(x):
    return 0.015 / np.cosh(1.5 * (x - 3.0))**2

solver = QuantumScattering1D(
    mass=2*1836.15/3, pes=sech2,
    n_grid=4000, grid_min=0.5, grid_max=9.0)
r = solver.solve(0.002, 0.05, 25)
print(np.column_stack((r.energy, r.transmission, r.reflection))[:])
print("max |T+R-1| =", np.max(np.abs(r.transmission+r.reflection-1)))
```

在项目根目录运行：

```bash
python -m pytest tests/test_dynamics.py -q
```

再做一次可信度实验：把 `n_grid` 依次设为 1000、2000、4000，比较曲线。阈值边缘对网格最敏感；不要只凭一条视觉平滑曲线声称精度。

## 7. 常见陷阱

- 能量必须与 PES 使用同一零点；`k²=2m(E−V)` 不容许混用相对势垒高度和绝对总能。
- 边界若进入强势区，渐近平面波假设失效，$T,R$ 不再可信。
- 垒下不是“波函数为零”，而是禁阻区内指数衰减；若数值显示强振荡，应检查网格与递推稳定性。
- 看到代码末尾归一化 $T+R$ 不等于可以忽略边界和离散误差；它只做有限网格清理。
- 二维 `QuantumReaction2D` 无横向动能、无流归一化，禁止用其数值宣称反应截面或阈值。
- 波包结果不能与 $T(E_0)$ 点值直接比较；应做能量加权积分 $\int|\tilde\psi(p)|^2T(p^2/2\mu)\,dp$。

## 8. 高手专栏

Numerov 可以视作对 Schr 算符的六阶多项式近似，也可从矩阵指数或三点关系理解。边界条件的有限截断误差与离散误差相互竞争：增大网格能降低 $O(h^4)$，缩短网格则减小两端反射污染，实际计算应同时做两项收敛。

若两端波数不同，散射矩阵系数与概率不必相同。精确 S 矩阵的幺正性在振幅通量归一化下成立；$T,R$ 是由相应通量归一化得到的数。仓库实现使用有限平均势和单次重归一化，适合教学和一般光滑一维势，不等同于经过高精度 scattering 库验证的 log-derivative、匹配法或谱方法。

含时与定态也可互相检验。可分离二维 Eckart 体系给出严格桥梁：二维波包应等于高斯动量分布对一维谱透射率的加权和。若中心能量恰位于陡峭阈值，比较点值会制造“代码不一致”的假象。
