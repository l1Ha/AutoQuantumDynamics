# AutoQuantum: 分子反应动力学全维量子动力学自动实现平台

## 1. 量子散射基础理论

### 1.1 一维薛定谔方程

一维定态薛定谔方程:

$$-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} + V(x)\psi = E\psi$$

在原子单位制 (au) 中, $\hbar = 1$, 因此方程简化为:

$$-\frac{1}{2m}\frac{d^2\psi}{dx^2} + V(x)\psi = E\psi$$

### 1.2 透射与反射系数

对于一维散射问题, 透射系数 $T$ 和反射系数 $R$ 满足:

$$T = \frac{k_{\text{trans}}}{k_{\text{inc}}} |A_{\text{trans}}|^2$$
$$R = |A_{\text{ref}} / A_{\text{inc}}|^2$$

其中 $k = \sqrt{2m(E - V)}$ 为局域波矢, $A$ 为波函数振幅。

守恒律: $T + R = 1$

### 1.3 数值方法

- **Numerov 算法**: 求解一维定态薛定谔方程的数值积分方法
- **Log-Derivative 方法**: Johnson 提出的散射问题稳定算法
- **分裂算符法 (Split-Operator)**: 含时波包传播的标准方法

## 2. 势能面 (PES) 理论

### 2.1 Morse 势

双原子分子振动的常用模型:

$$V(r) = D_e [1 - e^{-\alpha(r - r_e)}]^2$$

- $D_e$: 解离能 (H₂: 0.1744 au)
- $r_e$: 平衡键长 (H₂: 0.7416 Å)
- $\alpha$: 势能宽度参数 (H₂: 1.028 au⁻¹)

### 2.2 Lennard-Jones 势

$$V(r) = 4\epsilon [(\sigma/r)^{12} - (\sigma/r)^6]$$

### 2.3 神经网络拟合

使用前馈神经网络 (FFNN) 对 PES 数据点进行拟合:

- 输入层: 1 个节点 (键长)
- 隐藏层: 可配置宽度和深度
- 输出层: 1 个节点 (势能值)
- 激活函数: tanh / sigmoid / ReLU

## 3. AutoQuantum 流程

