# 势能面构建与神经网络拟合知识库

## 1. 势能面 (PES) 概述

势能面是分子反应动力学的核心, 描述了分子体系能量随原子核坐标的变化。

### 1.1 波恩-奥本海默近似

电子运动与核运动分离:
- 电子态能量 $E_n(\mathbf{R})$ 作为核坐标的函数
- PES = $E_0(\mathbf{R})$ (基态势能面)

### 1.2 坐标表示

- **内坐标**: 键长、键角、二面角
- **Jacobi 坐标**: 适用于散射问题
- **超球坐标**: 适用于多原子反应

## 2. PES 构建方法

### 2.1 从头算 (Ab Initio)

| 方法 | 精度 | 成本 | 适用体系 |
|------|------|------|---------|
| CASSCF | 中等 | 高 | 基态/激发态 |
| MRCI | 高 | 很高 | 高精度需求 |
| CCSD(T) | 高 | 高 | 闭壳层体系 |
| DFT | 中-高 | 低 | 大体系 |

### 2.2 解析势函数

- **Morse 势**: 双原子分子振动
- **LEPS 势**: 三原子反应 (H + H₂)
- **多体展开**: 多原子体系

## 3. 神经网络拟合

### 3.1 网络架构

```
Input (1) → Hidden Layer 1 (64) → Hidden Layer 2 (64) → Hidden Layer 3 (32) → Output (1)
```

### 3.2 训练策略

- 数据归一化: 输入输出标准化
- 学习率: 0.001 (Adam) / 0.01 (SGD)
- 早停 (Early Stopping): patience=50
- 训练/验证集: 80%/20%

### 3.3 评价指标

- 均方误差 (MSE): $\frac{1}{N}\sum(y_i - \hat{y}_i)^2$
- 最大绝对误差 (MAE): $\max|y_i - \hat{y}_i|$
- 决定系数 ($R^2$): $1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$

## 4. 示例: H₂ 分子

H₂ Morse 势参数 (原子单位):
- $D_e = 0.1744$ Hartree
- $\alpha = 1.028$ Bohr⁻¹
- $r_e = 0.7416$ Å = 1.401 Bohr

平衡位置附近振动频率: $\omega = \alpha \sqrt{2D_e/m} \approx 0.0187$ au
